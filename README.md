# Array Manipulation Using C++

## About the Project
This project contains beginner-friendly C++ programs based on array manipulation. It demonstrates how to perform different operations on arrays using loops, conditional statements, and switch-case statements.

## Programs Included

1. **Array Manipulation Using Switch Case** – Displays, inserts, deletes, and searches array elements and calculates their sum.
2. **Addition of Two Arrays** – Adds corresponding elements of two arrays.
3. **Subtraction of Two Arrays** – Subtracts corresponding elements of two arrays.
4. **Multiplication of Two Arrays** – Multiplies corresponding elements of two arrays.
5. **Largest and Smallest Element** – Finds the maximum and minimum elements in an array.
6. **Average of Array Elements** – Calculates the average of the numbers stored in an array.

## Technologies Used
- C++
- Arrays
- Loops
- Switch-case statements
- Conditional statements

## How to Run the Programs

1. Download or clone this repository.
2. Open any `.cpp` file in a C++ compiler or IDE.
3. Compile and run the program.
4. Enter the required input to see the output.

### Compile Using g++
```bash
g++ 02_add_two_arrays.cpp -o add_arrays
```

### Run the Program
```bash
./add_arrays
```

On Windows, you can run the compiled program using:
```bash
add_arrays.exe
```

Change the source filename in the compilation command to run a different program.
